# 퀴즈쇼 / 투표 (GitHub Pages + Supabase)

100명 안팎이 휴대폰으로 동시에 참여하는 실시간 퀴즈·투표 프로그램입니다.
서버 비용 없이 **GitHub Pages(화면)** 와 **Supabase 무료 플랜(실시간 DB)** 으로 돌아갑니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 참가자 | `https://<아이디>.github.io/<저장소>/` | 참가자 휴대폰 (QR로 접속) |
| 스크린 | `.../screen.html` | 빔프로젝터·TV |
| 진행자 | `.../host.html` | 진행자 노트북 (PIN 필요) |
| 디자인 시스템 | `.../design-system.html` | 색·글꼴·캐릭터 규칙 모음 |

**내 아바타:** 참가자는 입장할 때 머리 8 · 머리색 8 · 피부 4 · 눈 5 · 수염 4 · 옷 7 · 옷색 8 · 소품 7 을 골라 꼬마 아바타를 꾸미고, 이름을 붙입니다. **'밤티 되기'** 버튼 하나로 요즘 유행하는 밤티(갈색 웨이브 장발 + 턱수염 + 퀭한 눈 + 토가 + 천사날개)도 바로 만들 수 있어요.
결과를 공개하면 스크린의 보기마다 그 보기를 고른 사람들의 아바타가 이름표를 달고 바글바글 모여요. 정답 쪽은 신나서 점프하고, 오답 쪽은 눈물을 글썽이며 흔들립니다. 투표 문항은 모이는 모습이 실시간으로 보입니다.

---

## 1. Supabase 준비 (10분)

1. <https://supabase.com> 가입 → **New project** 생성 (리전은 `Northeast Asia (Seoul)` 추천)
2. 왼쪽 메뉴 **SQL Editor** → `supabase.sql` 파일 내용을 전부 붙여넣기
3. 맨 아래 줄의 `'CHANGE-ME-1234'` 를 **나만 아는 진행자 PIN** 으로 바꾸고 **Run**
4. **Project Settings → API** (또는 상단 **Connect** 버튼)에서 두 값을 복사
   - Project URL (`https://xxxx.supabase.co`)
   - `anon` `public` 키 또는 `sb_publishable_...` 키 (※ `service_role` / secret 키는 절대 넣지 마세요)

> 실시간 기능이 안 켜졌다면: **Database → Publications → supabase_realtime** 에서 `game` 테이블이 켜져 있는지 확인하세요. (SQL이 자동으로 켜 줍니다)

## 2. 설정 파일 수정

`config.js` 를 열어 1-4에서 복사한 값과 행사 이름을 넣습니다.

```js
export const SUPABASE_URL = 'https://xxxx.supabase.co';
export const SUPABASE_KEY = 'eyJhbGciOi...';   // anon 키
export const TITLE = '2026 송년회 퀴즈쇼';
```

## 3. GitHub Pages 배포

1. GitHub에서 새 저장소 생성 (Public)
2. 이 폴더의 파일을 전부 업로드 (**Add file → Upload files** 로 끌어다 놓기)
3. 저장소 **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`** → Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 로 접속 확인

## 4. 문항 만들기

진행자 화면의 **틀 추가** 버튼(정답 퀴즈 · OX 퀴즈 · 투표 · 숫자 순서 · 반응속도 · 광클)을 누르면 편집기에 형식이 자동으로 들어가요.

`host.html` 에서 PIN으로 로그인 → 오른쪽 **문항 편집** 칸에 아래 형식으로 쓰고 **문항 저장**.

```
Q: 대한민국의 수도는?
- 부산
* 서울          ← * 가 정답
- 대구
T: 15           ← 제한시간(초). 생략하면 20초

P: 점심 메뉴 투표   ← P: 는 정답 없는 투표 (시간 무제한)
- 한식
- 중식
```

- 문항 사이에는 **빈 줄**, 보기는 2~6개, `#` 으로 시작하는 줄은 메모
- **OX 퀴즈:** `OX: 문장` 다음 줄에 `정답: O` 또는 `정답: X`
- **공개 방식:** `공개: 실시간`(고르는 즉시 아바타 이동) · `공개: 정답때`(정답 공개 때) · `공개: 비공개`(누가 뭘 골랐는지 끝까지 비밀, 인원수와 %만). 생략하면 퀴즈는 정답때, 투표는 실시간
- **미니게임:** `G: 숫자순서`(+ `크기: 4`), `G: 반응속도`, `G: 광클`(+ `T: 10`). 순위대로 1000점(1등)~100점(꼴찌)이 전체 점수에 더해져요
- 문항(정답 포함)은 Supabase에만 저장되므로 참가자는 정답을 미리 볼 수 없습니다

## 5. 진행 순서

1. 빔프로젝터에 `screen.html` 을 띄우면 **참가 QR** 이 나옵니다 (전체화면: F11)
   - 오른쪽 위 **"클릭해서 소리 켜기"** 를 한 번 눌러 주세요 (브라우저 정책상 클릭 전에는 소리가 안 나요)
   - 효과음(입장·시작·카운트다운·부저·팡파르·드럼롤)과 배경음악은 브라우저가 직접 만들어 저작권 걱정이 없습니다
   - 원하는 음악이 있으면 `assets/bgm-lobby.mp3`(대기·엔딩), `assets/bgm-question.mp3`(문제 풀이) 로 넣으면 자동으로 그 파일을 재생합니다
2. 참가자가 QR로 접속 → 닉네임 입력
3. 진행자는 큰 노란 버튼(또는 **스페이스바**) 하나로 진행합니다
   `문항 시작 → 응답 마감 → 정답 공개 → 순위 보기 → 다음 문항 …→ 최종 결과`
   - 제한시간이 끝나면 자동 마감
   - 진행자 화면에는 응답 분포가 실시간으로 보이고, 스크린에는 퀴즈의 경우 정답 공개 때까지 응답 수만 보입니다
   - **돋보기:** 결과 화면에서 보기 카드의 🔍 버튼을 누르거나 스크린 노트북에서 숫자키 **1~6** 을 누르면, 그 보기를 고른 사람들만 화면 가득 크게(이름까지 잘 보이게) 보여 줍니다. **Esc** 또는 같은 숫자키로 닫혀요
4. 행사가 끝나면 **전체 초기화** 로 데이터를 지우세요

**점수:** 정답 500점 + 빠르기 보너스 최대 500점 (빨리 맞힐수록 높음). 투표 문항은 점수 없음.

## 채팅 · 댄스 · 크게 보일 사람

- 참가자 폰 아래 바: **댄스 1·2·3**(스크린 속 내 아바타가 3초간 춤) · **💬 채팅**(스크린 오른쪽 채팅창에 표시, 40자, 3초에 한 번, 기본 욕설 가림)
- 진행자 화면 **채팅 끄기** 버튼으로 언제든 채팅창을 닫을 수 있어요
- 채팅은 스크린을 새로고침해도 남아 있어요. **채팅 지우기** 버튼이나 초기화를 누를 때만 비워져요
- 진행자 화면 **참가자 목록에서 ★** 를 누른 사람은 스크린에서 2배 크게, 이름은 금색으로 보여요

## 업데이트 적용하기

1. 새 zip을 풀고, **내 `config.js` 는 그대로 둔 채** 나머지 파일만 GitHub 저장소에 **Add file → Upload files** 로 올려 **Commit changes** (같은 이름은 덮어써져요)
2. `supabase.sql` 이 바뀐 업데이트라면 SQL Editor에서 **다시 실행** (PIN은 바뀌지 않아요)
3. 1~2분 뒤 **Ctrl + Shift + R** 로 새로고침

## 리허설 체크리스트

- [ ] 행사 1~2일 전에 Supabase 대시보드에 한 번 접속 (무료 프로젝트는 오래 안 쓰면 일시정지됨)
- [ ] 휴대폰 3~4대로 처음부터 끝까지 한 번 돌려 보기 → **점수만 초기화** 또는 **전체 초기화**
- [ ] 행사장 와이파이가 약하면 "모바일 데이터로 접속해도 돼요" 안내
- [ ] 진행자 PIN은 `host.html` 주소와 함께 다른 사람에게 공유하지 않기

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "설정이 필요합니다" | `config.js` 값을 넣었는지 |
| 화면 왼쪽 위 점이 빨간색 | 실시간 연결 안 됨 → 그래도 약 10초마다 자동 갱신됨. Publications에서 `game` 테이블 확인 |
| 진행자 PIN 오류 | SQL 맨 아래 PIN을 바꾼 뒤 다시 Run 했는지 |
| 참가자가 새로고침함 | 같은 기기·브라우저면 닉네임과 점수가 그대로 유지됩니다 |

## 용량 참고 (Supabase 무료 플랜)

- 실시간 동시 접속 200개 → 참가자 100명 + 스크린 + 진행자 여유 있음
- 투표는 실시간 메시지가 아닌 DB 저장 방식이라, 100명이 동시에 눌러도 메시지 한도에 걸리지 않습니다
- 참가자는 최대 500명까지 받도록 되어 있습니다 (`supabase.sql` 의 `>= 500`)

```
tokens.css                 ★ 디자인 토큰 (색·글꼴·간격·모서리)
design-system.html         디자인 시스템 문서
screen.html / screen.js    스크린 화면

```
